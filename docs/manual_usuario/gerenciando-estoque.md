# Gerenciando Estoque
<h6>Atualize seu estoque quantas vezes forem necessárias!</h6>
---

## Categorias

Organize os itens do seu estoque em categorias personalizadas. Saiba como encontrá-las:

__1.__ Acesse o menu <span class="text-laranja">Configurações</span> e siga para <span class="text-laranja">Categorias</span>.

__2.__ Adicione as categorias de produtos que melhor atendem o seu negócio. 

__3.__ Salve as alterações ao término das mudanças.

???+ tip "Dica"
    - Produtos já cadastrados podem ser editados a qualquer momento no menu <span class="text-laranja">Estoque</span>.

???+ tip "Dica"
    - Categorias não existentes são criadas automaticamente quando inseridas no cadastro de produtos via planilhas.

## Editando itens no estoque

__1.__ Acesse o menu <span class="text-laranja">Estoque</span>.

__2.__ Selecione a opção <span class="text-laranja">Consultar Produtos</span> para acessar todos os itens cadastrados.

__3.__ Pesquise e selecione o produto desejado.

__4.__ Salve as alterações ao término das mudanças.

Todas as mudanças podem ser acompanhadas no <span class="text-laranja">Histórico de Movimentação</span> na tela inicial.
