# Cadastrando Fornecedores
<h6>Gerencie seus parceiros de negócios em um só lugar</h6>
---

No MILO, por padrão, todo produto cadastrado deve constar um fornecedor. Saiba como cadastrar seus colaboradores:

__1.__ Acesse o menu <span class="text-laranja">Estoque</span> e siga para <span class="text-laranja">Fornecedores</span>.

__2.__ Preencha os campos com as informações solicitadas.

__3.__ Salve as mudanças.
