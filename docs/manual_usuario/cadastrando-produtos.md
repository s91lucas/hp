Cadastrar seus produtos no MILO é simples como parece! 

---

## Cadastro Manual

![Image](./img/estoque1.png)

Insira todos os dados pendentes como solicitado pelo sistema e clique em <span class="text-laranja">Cadastrar</span> para realizar o cadastro. É possível cadastrar diversos produtos simultaneamente ao apertar o botão <span class="text-laranja">Adicione mais um produto</span>. Todas essas informações são relevantes e serão utilizadas para performar os <span class="text-laranja">[Relatórios de vendas](#)</span>, então preencha com cautela.

Todos os produtos cadastrados podem ser encontrados na [Planilha de Produtos](consulta.md).

---
## Importando Planilhas

O Sistema MILO oferece suporte a planilhas com formato predeterminado para cadastro de diversos produtos ao mesmo tempo!

*img*

Em **Ver modedelo de planilha** é possível visualizar o formato aceito pelo sistema.

---
## Consultando estoque
Consulte seu estoque adentrando a aba de **Estoques** e em seguida clicando em **Consultar produtos**.

MILO conta com uma barra de pesquisa para facilitar suas buscas!

Lá também é possível visualizar todos os produtos já cadastrados no sistema, assim como editar informações e excluí-los.
