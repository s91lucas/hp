# Cadastro de Vendas
---

__1.__ Acesse o menu <span class="text-laranja">Vendas</span> e siga para <span class="text-laranja">Cadastro de vendas</span>.

__2.__ Selecione os itens e quantidades a serem vendidas.

__3.__ Finalize a operação selecionando <span class="text-laranja">Criar venda</span>.

???+ tip "Dica"
    - MILO conta com uma opção para realizar vendas com preços variáveis.
    <p align="center"><img src="img/preco-unitario.png"/></p>
    - Dessa forma, descontos e preços avulsos podem ser aplicados sem precisar editar o valor de todos os itens em estoque.
