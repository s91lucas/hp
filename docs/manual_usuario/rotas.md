## Gerenciando rotas
### Gerar rota automaticamente

__1.__ Acesse o menu <span class="text-laranja">Rotas</span>.

__2.__ Preencha os campos.

__3.__ Ao terminar o preenchimento selecione <span class="text-laranja">Gerar rota</span> para receber um link <span class="text-laranja">_Google Maps_</span> contendo a melhor rota para sua entrega!

</p>

???+ tip "Dica"
    - Mais de um destino? Não tem problema! Selecione a opção <span class="text-laranja">Adicionar outro destino</span> para adicionar diversos <span class="text-laranja">pontos de paradas</span> a uma mesma rota.

### Gerar rota manualmente

O registre manual de rotas existe para que você possa registrar as <span class="text-laranja"> entregas realizadas sem o auxílio da plataforma</span>, mantendo seus Relatórios MILO atualizados e .

## Consultando rotas

__1.__ Acesse o menu <span class="text-laranja">Rotas</span>.

__2.__ Selecione o submenu <span class="text-laranja">Consultar rotas</span>.

__3.__ Nesta seção você tem acesso a todas as informações sobre rotas já cadastradas no sistema, links <span class="text-laranja">_Google Maps_</span>, tempo estimado de entrega, e mais.
